Privacy Policy

This policy covers the Broderick Ford Personal Alerts text messaging program, a private notification program run by Broderick Ford (sole proprietor).

Information collected

The program stores only one mobile phone number, belonging to the program owner, so that notifications can be delivered to him. No information is collected from members of the public.

How information is used

The phone number is used only to send the personal account and system notifications described on the opt-in page.

Sharing

No mobile information will be shared with third parties or affiliates for marketing or promotional purposes. Text messaging originator opt-in data and consent will not be shared with any third parties. Information is shared only with the messaging provider (Twilio) as needed to deliver messages.

Opting out

Reply STOP to any message to stop receiving texts. Reply HELP for help.
